# Configuración del Envío de Correos Electrónicos con FormSubmit

Este documento explica cómo funciona el envío de correos electrónicos para los formularios de contacto utilizando FormSubmit, una solución completamente gratuita y sin registro.

## ¿Qué es FormSubmit?

FormSubmit es un servicio gratuito que permite recibir los datos de formularios HTML directamente en su correo electrónico, sin necesidad de escribir código de backend o registrarse en ningún servicio.

## Cómo Funciona

1. Los formularios de contacto están configurados para enviar los datos a FormSubmit
2. FormSubmit procesa los datos y los envía a su dirección de correo electrónico (andresfgonzalezaristizabal@outlook.com)
3. No se requiere ninguna configuración adicional ni registro

## Primera Vez que se Utiliza

La primera vez que alguien envíe un formulario:

1. FormSubmit enviará un correo de activación a su dirección de correo electrónico
2. Debe hacer clic en el enlace de activación en ese correo para confirmar su dirección
3. Después de la activación, todos los envíos futuros de formularios llegarán directamente a su bandeja de entrada

## Configuración Actual

Los formularios están configurados con las siguientes opciones:

- **Destinatario**: andresfgonzalezaristizabal@outlook.com
- **Asunto**: Personalizado según el tipo de formulario (ej: "Nuevo formulario de contacto: Web & E-commerce")
- **Formato**: Tabla (para mejor legibilidad)
- **Captcha**: Desactivado (para simplificar la experiencia del usuario)
- **Redirección**: Después del envío, el usuario es redirigido a cafe-menu.html

## Ventajas de FormSubmit

- **Completamente gratuito**: Sin límites de envíos
- **Sin registro**: No necesita crear una cuenta
- **Sin código de backend**: Funciona con HTML puro
- **Fácil de usar**: Configuración mínima
- **Personalizable**: Múltiples opciones de configuración

## Solución de Problemas

Si no recibe los correos electrónicos:

1. **Verifique la carpeta de spam**: Los primeros correos pueden llegar a la carpeta de spam
2. **Confirme la activación**: Asegúrese de haber hecho clic en el enlace de activación en el primer correo
3. **Pruebe con otro navegador**: Algunos bloqueadores de anuncios pueden interferir con FormSubmit

## Limitaciones

- No hay panel de administración para ver los envíos históricos
- No hay almacenamiento de datos (solo se envían por correo electrónico)
- Depende de la disponibilidad del servicio FormSubmit
