Portfolio 3D Interactivo

🛠️ Stack Tecnológico

Three.js Blender WebGL GSAP JavaScript ES6+ GLSL

📋 Descripción del Proyecto

Este es más que un portfolio, es un pedacito de mi vida convertido en código. Una experiencia inmersiva que combina tecnología y creatividad para mostrar mis proyectos de manera única e interactiva.

Desarrollado desde cero con Three.js, incluye un sistema de navegación innovador que permite explorar proyectos y habilidades de manera completamente inmersiva con modelos optimizados, iluminación dinámica y shaders personalizados.

🚀 Funcionalidades Principales

  • Navegación 3D Inmersiva: Recorrer libremente el modelo 3D con controles intuitivos
  • Portfolio Interactivo: Explorar proyectos con transiciones suaves y animaciones
  • Información Personal: Acceder a mi historia, experiencia y trayectoria profesional
  • Servicios Profesionales: Descubrir los servicios que ofrezco con detalles específicos
  • Sistema de Contacto: Contactarme directamente desde la plataforma integrada
  • Optimización Performance: Carga progresiva de assets y optimización para móviles
  • Experiencia Responsive: Adaptación perfecta a todos los dispositivos
  • Créditos y Referencias: Acceso completo a documentación y referencias del proyecto
