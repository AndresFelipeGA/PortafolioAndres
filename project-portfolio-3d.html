📋 Descripción del Proyecto

Una experiencia inmersiva que combina tecnología y creatividad para mostrar mis proyectos de manera única e interactiva.

Desarrollado con Three.js, incluye navegación innovadora, modelos optimizados, iluminación dinámica y shaders personalizados.

🚀 Funcionalidades Principales

  • Navegación 3D Inmersiva: Controles intuitivos para explorar el modelo
  • Portfolio Interactivo: Proyectos con transiciones y animaciones
  • Información Personal: Historia y trayectoria profesional
  • Servicios Profesionales: Detalle de servicios disponibles
  • Sistema de Contacto: Comunicación directa integrada
  • Optimización Performance: Carga progresiva y responsive
