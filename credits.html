Sobre este proyecto:

This interactive 3D portfolio was completely developed from scratch using modern web technologies. El proyecto incluye un servidor Node.js personalizado con API de SendGrid para el manejo de formularios, containerization with Docker for deployment, and an immersive 3D experience built with Three.js.

Características técnicas:
✨ Renderizado 3D en tiempo real con optimización de performance
📱 Diseño completamente responsivo para todos los dispositivos
🔄 Sistema de navegación fluido entre secciones
📧 Formularios funcionales con envío automático de emails
🎵 Integración multimedia con audio ambiente
🐳 Deployment automatizado con Docker
